# Management Strategy Evaluation (MSE) for the North-Central stock of Peruvian anchovy

<br clear="right">

> **Primary documentation language:** Spanish. [Versión en español](README.md) - [Repository map](REPOSITORY_MAP.en.md)

This repository develops a reproducible Management Strategy Evaluation workflow for the **North-Central stock of Peruvian anchovy (*Engraulis ringens*)**.

The project is led scientifically by **DIPEL-IMARPE** and is designed to evaluate candidate management procedures under biological, fishery, observation, assessment, and implementation uncertainty. It is currently in scientific initialization; no management procedure, operating-model structure, time step, spatial structure, or reference point is considered adopted unless supported by traceable evidence and a documented scientific decision.

The GitHub repository is public, but institutional raw, intermediate, processed, and internal output data remain outside Git according to [`DATA_POLICY.md`](DATA_POLICY.md).
