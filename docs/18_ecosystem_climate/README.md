# Ecosistema y clima

La anchoveta es una especie forrajera de importancia ecosistémica y presenta fuerte variabilidad ambiental. Este componente evalúa qué procesos ecosistémicos o climáticos son suficientemente materiales para incorporarse al MSE o a sus pruebas de robustez.

Considerar, sin asumir inclusión automática:

- variabilidad y regímenes ambientales;
- no estacionariedad climática;
- cambios de productividad y distribución;
- mecanismos ambiente-reclutamiento con sustento ecológico;
- demanda de depredadores o restricciones de biomasa forrajera cuando sean objetivos de manejo relevantes.

Si una MP usa directamente información ambiental, debe probarse también bajo escenarios donde la relación histórica se debilite o deje de ser estable.
