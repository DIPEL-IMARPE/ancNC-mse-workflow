# Evaluación de stock de anchoveta Norte-Centro

Esta carpeta documenta la evaluación de stock que sustenta el asesoramiento científico y permite decidir qué Estimation Model utilizará el closed loop.

Documentar:

- estructura del modelo de evaluación;
- series de datos utilizadas;
- parámetros estimados y fijados;
- crecimiento, mortalidad natural, madurez y selectividad;
- tratamiento del reclutamiento;
- índices y composiciones;
- likelihoods, priors o ponderaciones cuando correspondan;
- diagnósticos, convergencia y retrospectiva;
- incertidumbre;
- puntos de referencia y forma de producir asesoramiento.

El Estimation Model del MSE puede ser la evaluación completa, una versión reducida, un surrogate o un procedimiento empírico. Esa decisión debe justificarse y no asumirse desde el inicio.
