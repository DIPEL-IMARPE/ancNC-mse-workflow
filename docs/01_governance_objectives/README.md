# Objetivos de manejo y tolerancias de riesgo

Esta carpeta debe documentar **qué significa un buen desempeño del manejo de la anchoveta Norte-Centro antes de diseñar o seleccionar una MP**.

Se deben distinguir objetivos de conservación, pesquería, estabilidad, ecosistema y, cuando corresponda, económicos o sociales. Cada objetivo debe vincularse con una métrica, horizonte temporal y tolerancia de riesgo en `registry/objective_registry.csv`.

No se deben fijar aquí valores de riesgo por conveniencia del modelador; deben provenir del proceso científico y de manejo correspondiente.
