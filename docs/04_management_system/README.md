# Sistema de manejo de la anchoveta Norte-Centro

Esta carpeta reconstruye **cómo funciona realmente el manejo**, no cómo quisiéramos representarlo en el MSE.

Debe documentarse la secuencia completa:

`monitoreo -> evaluación científica -> recomendación -> decisión -> apertura/medidas -> pesca -> monitoreo intra-temporada -> ajustes/cierres -> cierre de temporada`.

Inventariar, con evidencia y fecha, las medidas relevantes: cuotas/LMTCP, mecanismos de asignación cuando sean pertinentes al nivel del MSE, temporadas, vedas, cierres espaciales o temporales, medidas asociadas a juveniles, protección reproductiva, decisiones precautorias, exploratorias y cualquier discreción institucional material.

La reconstrucción del **status quo** debe derivarse de esta evidencia antes de codificarse como Management Procedure de referencia.
