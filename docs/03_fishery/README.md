# Pesquería de anchoveta Norte-Centro

Esta carpeta debe describir el sistema pesquero que interactuará con el modelo operativo y con las medidas de manejo.

Documentar, según disponibilidad:

- segmentos de flota y características relevantes;
- capacidad y esfuerzo;
- selectividad y cambios temporales;
- disponibilidad/capturabilidad;
- distribución espacial de la actividad;
- temporadas y patrones intra-temporada;
- cambios tecnológicos;
- respuesta de la flota a cuotas, cierres, disponibilidad y redistribución del recurso.

La complejidad de la flota dentro del MSE se decidirá después de esta síntesis; no se asumirá automáticamente una única flota ni una estructura multiflota.
