# Monitoreo y datos de la anchoveta Norte-Centro

Esta carpeta describe cómo se observa el sistema y qué errores o limitaciones deberán representarse en el Observation Model.

Revisar como mínimo:

- cruceros hidroacústicos: diseño, frecuencia, cobertura, biomasa/abundancia, precisión, disponibilidad y cambios metodológicos;
- captura/desembarque y esfuerzo;
- composiciones de talla y esquema de ponderación;
- muestreo biológico y reproductivo;
- monitoreo de juveniles;
- cobertura espacial y temporal de la pesquería;
- datos ambientales usados como contexto o hipótesis;
- cambios de protocolo, datos faltantes y control de calidad.

Distinguir siempre **estado verdadero**, **proceso de observación** y **dato finalmente disponible para la evaluación o MP**.
