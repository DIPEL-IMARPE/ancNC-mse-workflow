# Incertidumbre y escenarios del MSE de anchoveta Norte-Centro

La incertidumbre debe organizarse en:

- **Reference Set**: hipótesis principales científicamente plausibles usadas para la evaluación central y, cuando corresponda, tuning;
- **Robustness Set**: hipótesis alternativas o condiciones difíciles usadas para comprobar robustez.

Candidatos a evaluar, sin asumir todavía que todos deban modelarse, incluyen:

- variabilidad, autocorrelación y cambios de régimen del reclutamiento;
- fallas persistentes de reclutamiento;
- cambios de crecimiento o condición;
- incertidumbre en mortalidad natural;
- selectividad variable;
- disponibilidad o sesgo del índice acústico;
- ausencia o cobertura parcial de cruceros;
- error en composiciones de talla y muestreo de juveniles;
- retrasos o error de implementación;
- redistribución espacial de recurso y flota;
- no estacionariedad ambiental;
- debilitamiento o ruptura de relaciones ambiente-reclutamiento.

Toda incertidumbre incluida debe registrarse en `registry/uncertainty_registry.csv` y vincularse con evidencia o una justificación científica.
