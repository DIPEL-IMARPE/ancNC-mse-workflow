# Datos públicos autorizados

Esta carpeta contiene **únicamente datos cuya redistribución pública ha sido comprobada y autorizada** para `ancNC-mse-workflow`.

Antes de añadir un archivo:

1. registre el conjunto en `registry/data_inventory.csv`;
2. identifique la fuente en `registry/source_registry.csv`;
3. documente licencia, permiso o fundamento de redistribución;
4. indique unidades, cobertura y transformaciones relevantes.

No copie aquí datos institucionales solo porque estén disponibles para el equipo.
