# Datos originales restringidos

Esta carpeta es un **marcador local** para datos primarios del proyecto que no están autorizados para entrar al historial de Git. Su contenido está ignorado por `.gitignore`.

Pueden incluir, sujeto a las autorizaciones institucionales correspondientes, datos originales de cruceros, pesquería, muestreos biológicos, evaluaciones u otras fuentes internas.

GitHub solo debe contener este README, su versión en inglés y `.gitkeep`; nunca las observaciones restringidas.
