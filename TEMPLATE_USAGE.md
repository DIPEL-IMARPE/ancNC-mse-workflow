# Origen del repositorio

`ancNC-mse-workflow` fue creado a partir de `qselmer/.template-fisheries-mse` v1.0.3.

Este repositorio **ya no es una plantilla genérica**: corresponde al caso de anchoveta peruana, stock Norte-Centro. La arquitectura heredada se conserva para mantener consistencia, trazabilidad y posibilidad de reutilizar las mismas convenciones en futuros MSE.

Las futuras mejoras generales de la plantilla no deben copiarse automáticamente al proyecto. Cada cambio debe evaluarse y versionarse en este repositorio.
